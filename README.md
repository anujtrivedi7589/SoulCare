### 💜 SoulCare - Mental Wellness Platform

Your safe space for mental well-being.
A modern web platform for self-assessment, wellness blogs, and mood tracking.

### 🚀 Overview
SoulCare is a mental health platform designed to provide a calm and supportive digital environment. It includes self-assessment tools, wellness blogs, and daily mood tracking.

### ✨ Features
- 📝 Self-assessment quiz
- 🎧 Calming UI with smooth animations
- 📚 Wellness blogs
- 😊 Mood tracking
- 🌙 Dark/Light mode
- 📱 Fully responsive

### 🛠️ Tech Stack
- React.js
- Tailwind CSS
- Framer Motion
- JavaScript
- Vite

### ⚙️ How It Works
1. User visits the homepage
2. Explores wellness resources and blogs
3. Takes self-assessment quiz
4. Gets personalized insights and suggestions
5. Tracks mood and progress daily

### 📁 Project Structure
```
SoulCare/
├── src/
│   ├── components/  -> Reusable UI components
│   └── pages/       -> Home, About, Blogs etc
├── public/          -> Static assets
└── package.json
```

### ▶️ Getting Started
1. Install Dependencies
   ```
   npm install
   ```
2. Run the Project
   ```
   npm run dev
   ```
