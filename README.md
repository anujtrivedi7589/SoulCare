# 💜 SoulCare - Mental Wellness Platform

  Your safe space to heal, grow, and find peace!
  A modern web platform for mental health awareness, self-assessment, and wellness resources.

### 🚀 Overview

SoulCare is a mental health focused web app that provides users with a calming and supportive environment. It offers mood tracking, self-assessment tools, wellness blogs, and resources to help users on their mental wellness journey.

### ✨ Features

- 🧠 Self-assessment quizzes for mental well-being
- 💬 Calming UI with smooth animations
- 📝 Wellness blogs and expert articles
- 🎯 Mood tracking and daily check-ins
- 🌙 Dark/Light mode support
- 📱 Fully responsive design

### 🛠️ Tech Stack

- React.js
- Tailwind CSS
- Framer Motion
- JavaScript
- Vite

### ⚙️ How It Works

1.  User visits the homepage
2.  Explores wellness resources and blogs
3.  Takes self-assessment quiz
4.  Gets personalized insights and suggestions
5.  Tracks mood and progress daily

### ▶️ Getting Started

1.  Install Dependencies
    npm install

2.  Run the Project
    npm run dev
